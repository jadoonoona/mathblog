전사와 단사의 성질
1.T는 V에서 W로 가는 선형 변환이라고 할 때, T가 "단사"인 것은 핵이 0인 것과 동치이다. (필요충분조건)
T가 단사(One-to-One) <-> ker(T) = {0}
2. T가 단사이고 A1,a2,...,an이 V의 기저이면, T(a1), T(a2), ..., T(an)은 T(V)의 기저이다.
3. dim(V) = dim(T(V))이면 T가 단사 <-> T가 전사(Onto)이다.

T가 V에서 W로의 선형변환이라 할 때, T가 "전사"이면서 "단사"이면 (즉,Im(T) = W이면서 ker(T) = {0}이면) T는 V와 W 사이의 동형공간(Isomorphic Space)이고 T는 동형변환(isomorphism)이라고 한다. 동형사상은 선형대수학에서 매우 중요한 개념으로, 두 벡터 공간이 구조적으로 동일하다는 것을 의미한다.

동형변환 T는 벡터공간의 덧셈과 스칼라곱셈을 보존하며, V와 W를 일대일대응시킴.

따라서 동형인 두 벡터 공간 V와 W는 사실상 동일한 벡터 공간으로 간주할 수 있다. 동형사상은 벡터 공간의 구조적 특성을 이해하는 데 중요한 도구로 사용된다. 

벡터의 직교 (Orthogonality)
1. 벡터공간 V의 부분집합 S가 서로 직교하는 벡터들로 이루어져 있다면, S는 V의 직교 집합이라고 한다.
2. 벡터공간 V의 내적공간에서 0이 아닌 벡터 A1, A2, ..., An이 서로 직교한다면, 일차독립임
3. 서로 직교인 0이 아닌 벡터들의 집합을 직교집합(Orthogonal Set)이라고 한다. 직교집합이 V의 기저가 될 때, 이를 직교기저(Orthogonal Basis)라고 한다.
4. 직교집합에서 각 벡터의 크기가 1이면 단위직교집합이고 W의 단위직교기저라 함
